# Vibe Code Setup Guide

## Overview

Vibe Code lets you interact with Claude Code hands-free from your iPhone using voice. A relay server on your Mac bridges to existing Claude Code sessions — you speak commands and hear back errors, questions, and completions.

## Prerequisites

- Mac with Claude Code installed and running in tmux
- iPhone running iOS 17+
- Node.js 22+ on your Mac

## Step 1: Start the Relay Server

```bash
cd relay-server
npm install
npm run dev
```

The server starts on port 3578 and auto-generates a JWT secret at `~/.vibe-code/relay-secret.key`.

## Step 2: Get Connection Info

```bash
# JSON payload for manual entry
curl localhost:3578/pair/json

# QR code in terminal (for scanning from iPhone)
curl localhost:3578/pair
```

The `/pair/json` endpoint returns:
```json
{
  "relayUrl": "ws://your-mac.local:3578/ws",
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "hostname": "your-mac.local"
}
```

## Step 3: Connect from iPhone

### Option A: QR Code (Recommended)
1. Open Vibe Code on iPhone
2. Tap "Scan QR Code"
3. Point camera at the QR code in your terminal

### Option B: Manual Entry
1. Open Vibe Code on iPhone
2. Tap "Manual Setup"
3. Enter the relay URL and token from Step 2

## Step 4: Select a Session

After connecting, Vibe Code discovers all your active Claude Code sessions. Tap one to attach.

Sessions are discovered by scanning `~/.claude/projects/` and correlating with active tmux panes.

## Step 5: Start Talking

1. **Tap the mic button** — speak your command
2. **Tap stop** — your speech is transcribed and sent to Claude Code
3. **Listen** — when Claude encounters an error or asks a question, you hear it spoken back

## Troubleshooting

### Relay server won't start
```bash
# Check if port is in use
lsof -i:3578

# Use a different port
RELAY_PORT=4000 npm run dev
```

### No sessions found
- Make sure Claude Code is running in a tmux session
- Check that `~/.claude/projects/` contains JSONL files
- Verify tmux is running: `tmux list-sessions`

### Phone can't connect
- Ensure phone and Mac are on the same network (or use Tailscale)
- Check the relay URL uses the correct hostname/IP
- Try using the Mac's IP address directly: `ws://192.168.x.x:3578/ws`

### Mic not working
- Grant microphone and speech recognition permissions in iOS Settings
- Check that no other app is using the microphone

### Health check
```bash
curl localhost:3578/health
# {"status":"ok","version":"0.1.0","uptime":123.4,"clients":1}
```

## Security

- **JWT auth**: Each connection requires a token generated by the relay server
- **Local network**: The relay server only needs to be reachable from your phone (LAN or VPN)
- **Token revocation**: Delete `~/.vibe-code/relay-secret.key` to invalidate all tokens
- **Keychain storage**: The iOS app stores the relay token in the secure Keychain
